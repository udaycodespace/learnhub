# Code of Conduct

This Code of Conduct applies to everyone contributing to **LearnHub**, including contributors, mentors, maintainers, reviewers, and project admins.

## Our standards

We expect everyone to:

* Treat others with **respect and professionalism**.
* Give and receive **constructive feedback**.
* Respect issue assignments, maintainers, and contribution boundaries.
* Submit **genuine and original work**.
* Follow LearnHub's rules, guidelines, and contribution process.

The following are not allowed:

* Copying another contributor's active PR and submitting it as your own.
* Creating fake or duplicate accounts to bypass contribution limits.
* Opening empty or meaningless PRs to gain points, XP, or visibility.
* Manipulating issues, labels, assignments, reviews, or scoring.
* Harassment, threats, discrimination, personal attacks, or retaliation.
* Any other dishonest, abusive, or disruptive behavior.

## Open Source Programs

> [!IMPORTANT]
> If **LearnHub participates in an external Open Source Program** and you participate in that program through LearnHub, you must follow **both**:
>
> **LearnHub's Code of Conduct + the Open Source Program's Code of Conduct and rules.**
>
> The rules of one do **not** replace the other.

All applicable **terms, conditions, guidelines, eligibility requirements, contribution limits, deadlines, scoring rules, and program policies** must be followed.

### Examples

| Situation                                        | Expected action                                              |
| ------------------------------------------------ | ------------------------------------------------------------ |
| An issue is assigned to another contributor      | **Do not submit the same work as your own.**                 |
| You find code in another contributor's active PR | **Do not copy and submit it as your solution.**              |
| You are unsure whether a contribution is allowed | **Ask a maintainer before submitting it.**                   |
| A program has stricter contribution limits       | **Follow the program's limits as well as LearnHub's rules.** |
| A program has its own Code of Conduct            | **Follow that COC along with this one.**                     |
| You make a genuine mistake                       | **Correct it and cooperate with the review process.**        |

> [!NOTE]
> **If a rule or term is unclear, ask before acting.** Not understanding a rule does not automatically make a violation acceptable.

## Enforcement

Depending on the **severity, frequency, and impact** of a violation, action may include:

| Action          | Possible outcome                                    |
| --------------- | --------------------------------------------------- |
| **Warning**     | Guidance or formal warning                          |
| **Restriction** | Temporary restriction from project activities       |
| **Removal**     | Removal from a contribution, repository, or program |
| **Ban**         | Permanent restriction from participation            |

Serious violations may result in immediate action.
